# Skill: /ec-playbook
**Objetivo:** Ativar e orquestrar o sistema completo de Estruturação Comercial (E.C) da V4 Company — 20 skills em sequência, do Kickoff à implementação do CRM. Esta é a skill de entrada do projeto: ela orienta o consultor sobre o que coletar, em que ordem executar cada skill e o que esperar de cada entregável.

---

## O que é a Estruturação Comercial (E.C)?

A E.C é o processo completo de diagnóstico, construção e entrega de uma operação comercial estruturada para um cliente da V4 Company. Ao final do projeto, o cliente recebe:

- Um diagnóstico honesto de onde sua operação está hoje
- Um processo comercial documentado (BPMN) pronto para ser executado
- Um Playbook Comercial completo — o manual operacional da equipe de vendas
- Uma Política de Comissionamento justa e calculada sobre os dados reais
- Um Forecast Comercial com projeção de 12 meses e plano de ação OKR
- Um CRM configurado com pipeline, automações e cadências prontas para uso
- Um estudo comparativo de ferramentas (CRM Sales e Marketing) para tomada de decisão

---

## O que você precisa antes de começar

Antes de acionar qualquer skill, garanta que você tem em mãos:

| Documento | Onde obter | Obrigatório? |
|---|---|---|
| **Plano de ROI** | Documento gerado na venda do projeto | ✅ Sim |
| **Acesso ao cliente** | Contato direto com o gestor e com 2 vendedores (1 top, 1 bottom) | ✅ Sim |
| **Exemplos de conversas reais com leads** | Solicitar ao gestor — WhatsApp, e-mail, qualquer canal | Recomendado |
| **Lista de ferramentas em uso** | Perguntar no Kickoff | Recomendado |
| **Histórico financeiro** | Faturamento dos últimos 6–12 meses, base de clientes, pipeline | Para as skills de gestão |
| **Export do CRM atual** | Se o cliente já usa CRM — pedir print ou export | Se existir |

## As 20 Skills em 5 Fases

### FASE 1 — Diagnóstico
> *Objetivo: entender o estado real da operação antes de propor qualquer solução*

| # | Skill | Entregável | Input necessário |
|---|---|---|---|
| 1 | `/ec-kickoff` | Lista de perguntas para a reunião de Kickoff | Plano de ROI |
| 2 | `/ec-entrevista-gestor` | Perguntas para entrevista com o gestor comercial | Transcrição do Kickoff |
| 3 | `/ec-entrevista-bottom` | Perguntas para entrevista com vendedor de menor performance | Transcrição do Kickoff + entrevista do gestor |

**Ao concluir a Fase 1, você tem:** um diagnóstico estruturado com Matriz de Maturidade, análise por pilar, gap de benchmarking e impacto estratégico. É com esse documento que você apresenta o diagnóstico ao cliente antes de começar a construção.

## Mapa de Dependências

```
ROI + Kickoff
     ↓
[F1] Entrevistas → Análise Geral
     ↓
[F2] Org. Pessoas → KPIs → Ferramentas → BPMN → Cadências → CHA → Scripts → SLA → Playbook
     ↓
[F3] Entrega de Processos (HTML)
     ↓
[F4] Comissionamento → Forecast → Entrega de Gestão (HTML)
     ↓
[F5] Stack (estudo de CRM) → CRM (configuração)
```

**Regra de dependência:** cada skill consome os outputs das anteriores. Nunca pular uma skill sem garantir que o dado que ela produziria está disponível de outra forma.

## Como usar esta skill

1. Digite `/ec-playbook`
2. Compartilhe o Plano de ROI do cliente
3. Receba: orientação sobre o que coletar, qual skill acionar primeiro e o que esperar de cada entregável na sequência
4. A partir daí, acione cada skill na ordem do mapa — compartilhando os outputs anteriores como input da próxima

---

## Regras gerais do sistema

1. Cada skill lê os inputs fornecidos e nunca inventa informação não presente nos documentos
2. Os outputs devem ser salvos na pasta `entregaveis/` do cliente
3. Dados não disponíveis são sinalizados com ⚠️ para revisão posterior — nunca preenchidos com suposição
4. O Playbook Comercial (skill 14) é o documento-mãe — sintetiza os outputs de todas as skills anteriores (1 a 13)
5. As skills de entrega (15 e 18) geram HTML — não texto. O output é um arquivo `.html` pronto para abrir no browser e converter para PDF
6. Sempre responder em português brasileiro
