# Padrão Visual — Entregáveis de Estruturação Comercial (E.C)

> Referência para aplicação futura. O conteúdo dos entregáveis é gerado em Markdown.
> A formatação visual abaixo deve ser aplicada manualmente no Google Docs / Word antes da entrega ao cliente.

---

## Paleta de Cores

| Elemento | Cor |
|---|---|
| Vermelho principal | `#C0272D` |
| Preto | `#000000` |
| Branco | `#FFFFFF` |
| Vermelho salmão (subseções) | versão mais clara do vermelho principal |

---

## Padrão Visual por Elemento

| Elemento | Fundo | Texto |
|---|---|---|
| Capa — título principal "PLAYBOOK DE VENDAS" | Vermelho | Branco bold, caixa alta |
| Capa — subtítulo "ESTRUTURAÇÃO COMERCIAL" | Preto | Branco bold, caixa alta |
| Capa — nome do cliente | Sem fundo | Preto bold |
| Capa — cidade, versão, ano | Sem fundo | Cinza regular |
| Capa — crédito V4 Company | Sem fundo | Vermelho bold |
| Header de página (topo) | Sem fundo | Vermelho bold + cinza regular + linha vermelha |
| Header de seção principal (ex: "1. TÍTULO") | Preto | Branco bold, caixa alta |
| Header de subseção (ex: "2.1. Título") | Vermelho salmão | Vermelho escuro bold |
| Header de sub-subseção (ex: "A. Título") | Sem fundo | Vermelho bold |
| Cabeçalho de tabela | Vermelho escuro | Branco bold, caixa alta |
| Primeira coluna de tabela (labels) | Sem fundo | Vermelho bold |
| Bloco "Frente" (destaque especial) | Preto | Vermelho + Branco |
| Bloco de nota / nota operacional | Cinza claro | Bold |
| Rodapé final ("documento vivo") | Vermelho | Branco bold |

---

## Hierarquia de Títulos no Documento

1. **Nível 1** — Fundo preto, texto branco bold, caixa alta → seções principais numeradas
2. **Nível 2** — Fundo vermelho salmão, texto vermelho escuro bold → subseções (2.1, 2.2...)
3. **Nível 3** — Sem fundo, texto vermelho bold → sub-subseções (A., B. ou título descritivo)
4. **Nível 4** — Texto bold inline no corpo do parágrafo

---

## Estrutura da Capa

```
[FUNDO VERMELHO] PLAYBOOK DE VENDAS
[FUNDO PRETO]    ESTRUTURAÇÃO COMERCIAL
[BOLD PRETO]     Nome do Cliente
[REGULAR]        Cidade — UF  |  Versão X.X  |  Ano
[VERMELHO BOLD]  Elaborado em parceria com V4 Company
```

## Sumário

- Fundo preto, texto branco bold: "SUMÁRIO"
- Itens numerados com número em vermelho bold e texto em preto regular
