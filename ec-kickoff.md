# Skill: /ec-kickoff
**Objetivo:** Gerar uma lista de perguntas estruturadas para a reunião de Kickoff com o cliente de Estruturação Comercial (E.C), com base no Plano de ROI compartilhado pelo departamento comercial.

---

## Instruções para o modelo

O usuário irá compartilhar o **Plano de ROI** do cliente. Você deve:

1. Ler e absorver todas as informações já contidas no Plano de ROI
2. Identificar o que já é conhecido (não perguntar o que já está respondido)
3. Identificar lacunas de informação necessárias para construir todos os entregáveis do fluxo de E.C
4. Gerar uma lista de perguntas estruturadas, organizadas por tema, prontas para serem feitas na reunião de Kickoff

As perguntas devem ser claras, diretas e adequadas para serem feitas ao gestor comercial ou dono da empresa. Evite jargões técnicos desnecessários.

---

## Entregáveis que as perguntas devem alimentar

As perguntas precisam gerar insumos suficientes para construir todos os documentos abaixo:

- Documento Geral de Análise
- Estrutura Organizacional e Pessoas
- Gestão, KPIs e Rituais
- Ferramentas Táticas e Operação
- BPMN (Fluxo de Processos Comerciais)
- Fluxos de Cadência
- Matriz CHA (SDR e Closer)
- Script de Vendas e Follow Up
- Acordo de Nível de Serviço - SLA (Marketing x Vendas)
- Playbook Comercial
- Política de Comissionamento
- DRE Projetado (6 meses)
- Stack Tecnológico Sugerido

---

## Temas obrigatórios das perguntas

Organize as perguntas nos seguintes blocos temáticos. Gere apenas as perguntas que o Plano de ROI ainda não respondeu:

### 1. Estrutura Organizacional e Pessoas
- Quem são os envolvidos na operação comercial (nome, cargo, função)?
- Existe separação entre quem prospecta e quem fecha?
- Há plano de contratação? Para qual perfil?
- Como é a hierarquia de decisão nas vendas?

### 2. Processo Comercial Atual
- Como é o processo de vendas hoje, do primeiro contato ao fechamento?
- Quais são as etapas que o cliente passa antes de comprar?
- Qual é o tempo médio de ciclo de venda?
- Quais são os principais motivos de perda de negócio?
- Como são feitas as propostas comerciais hoje?

### 3. Clientes e Mercado
- Quem é o cliente ideal (perfil, segmento, porte, cargo do decisor)?
- Quais são os principais clientes ativos hoje?
- Existe segmentação da base de clientes?
- Como os clientes chegam hoje (canais de origem)?
- Qual é o ticket médio por tipo de cliente/serviço?

### 4. Gestão, KPIs e Rituais
- Quais métricas comerciais são acompanhadas hoje?
- Existe algum ritual de gestão (reunião de pipeline, forecast)?
- Como são definidas e acompanhadas as metas?
- Quem é responsável por cobrar os resultados?

### 5. Ferramentas e Tecnologia
- Quais ferramentas são usadas hoje na operação comercial?
- Existe CRM? Se sim, qual e como é usado?
- Como os pedidos, propostas e contratos são registrados?
- Como é feita a comunicação interna da equipe comercial?

### 6. Cadência e Prospecção
- Como é feita a prospecção hoje (ativa, passiva, indicação)?
- Existe alguma cadência de follow up estruturada?
- Quais canais são usados para contato (telefone, e-mail, WhatsApp)?
- Qual é a frequência de contato com clientes inativos?

### 7. Perfil do Vendedor (para Matriz CHA)
- Qual é o perfil do vendedor ideal para essa operação?
- O que diferencia os vendedores de alta performance dos de baixa?
- Quais competências técnicas são indispensáveis?
- Quais comportamentos ou atitudes são inaceitáveis?

### 8. Comissionamento e Financeiro
- Como funciona a política de comissionamento hoje?
- Existe diferença de comissão por tipo de produto/serviço/cliente?
- Qual é a margem de contribuição média dos produtos/serviços?
- Quais são os principais custos da operação comercial?
- Qual é a meta de faturamento para os próximos 6 meses?

### 9. Marketing e SLA
- Como marketing e vendas se relacionam hoje?
- Existe definição de o que é um lead qualificado para vendas?
- Quem é responsável pelo que em cada etapa do funil?

### 10. Expectativas e Contexto do Projeto
- Qual é o principal resultado esperado com a Estruturação Comercial?
- Existe alguma iniciativa anterior que não funcionou? O que aconteceu?
- Qual é o prazo ideal para ver os primeiros resultados?
- Quem são as pessoas que precisam estar alinhadas com o projeto internamente?

---

## Formato de saída esperado

Gere a lista de perguntas no seguinte formato:

```
# Perguntas de Kickoff — [Nome do Cliente]

## Bloco 1: [Tema]
1. [Pergunta]
2. [Pergunta]

## Bloco 2: [Tema]
...
```

Ao final, adicione uma seção:

```
## Informações já mapeadas pelo Plano de ROI
- [Liste o que já é conhecido e não precisa ser perguntado]
```

---

## Como usar esta skill

1. Digite `/ec-kickoff`
2. Cole ou compartilhe o Plano de ROI do cliente
3. Receba a lista de perguntas estruturadas para a reunião de Kickoff
